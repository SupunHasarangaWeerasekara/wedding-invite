# Wedding Invitation Frontend

Next.js (App Router) + React + Tailwind CSS frontend application for the Digital Wedding Invitation (Sanjaya & Gagani).

## 🚀 Getting Started

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application:
- Invitation View: `http://localhost:3000/invite/VIP-KASUN7`
- Admin Dashboard: `http://localhost:3000/admin`

---

## 📁 Folder Structure
- `app/` - Next.js App Router (Guest views, Admin panel, API routes)
- `components/` - Shared UI components (EnvelopeCover, Countdown, Calendar, LightboxGallery, Heart Shower, etc.)
- `lib/` - Types, dummy data, and local store
- `public/` - Static assets and photos
